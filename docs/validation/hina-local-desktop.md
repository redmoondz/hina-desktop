# Hina Desktop 0.2.0 validation

## Product contract

Hina Desktop is a tray application for local dictation and voice commands to the existing Hina/OpenClaw agent. The existing recording overlay is preserved.

| Case                                                | Expected behavior                                                                      |
| --------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Normal launch                                       | Starts in the tray; settings open from its menu                                        |
| Dictation shortcut                                  | Records, transcribes locally, and pastes into the focused application                  |
| Hina shortcut                                       | Uses local transcription, then the authenticated loopback Connector                    |
| Legacy cloud preferences                            | Resolve to local Whisper without cloud fallback                                        |
| Cloud, login, billing, calendar or provider-key IPC | Returns `LOCAL_ONLY` before credentials or network access                              |
| Missing Connector                                   | Reports a configuration or connection error without another provider                   |
| Legacy assets                                       | Copies allowlisted Whisper/CUDA assets with SHA-256 verification, preserving originals |
| Settings close/reload                               | Keeps recorder readiness and global shortcuts active                                   |

The local Connector access token is required for the existing agent connection. It is distinct from provider API keys and is stored through the application credential interface. No agent model turn was required for validation.

## Live Windows checks

- The imported `ggml-large-v3-turbo.bin` is discovered under the registry ID `turbo`.
- The imported CUDA pack reports installed/current on NVIDIA GeForce RTX 5070.
- Local Whisper starts successfully with `gpuAccelerated: true`, `gpuBackend: cuda`, and `modelName: large-v3-turbo`.
- A WAV generated by the offline Windows speech synthesizer is transcribed successfully. Expected phrase: “Hina Desktop uses local speech recognition.” Actual text: “Hena desktop uses local speech recognition.”
- Direct cloud IPC returns `LOCAL_ONLY`.
- The existing OpenClaw Gateway remains unchanged. A separate `hina-connector.service` supplies the persistent loopback bridge; health/authentication checks do not invoke model inference.
- Settings are rendered at 1280 and 390 pixels in light/dark themes, including the top and bottom of the scrollable window. No horizontal overflow or console errors were found. Screenshot evidence is generated under `%TEMP%\hina-evidence` by `scripts/hina-inspect-win.cjs`.

## Verification commands

```sh
npm run quality-check
node --import tsx --test --test-concurrency=8 --test-timeout=180000 "test/**/*.test.js"
node scripts/hina-smoke-win.cjs C:\path\dictation.wav
node scripts/hina-inspect-win.cjs
```

The first broad Windows run completed 8,586 tests: 8,032 passed, 57 failed, 496 skipped and one TODO. It exposed test-locale assumptions, cache fixture paths, missing Windows symlink privileges and an Electron/Node SQLite ABI mismatch. Relevant fixtures were repaired and rerun. The prior-session upstream run also had failures (38), including platform-dependent tests. Broad-suite results must not be presented as an all-green result.

After repairs, all 40 changed/new test files completed with 342 passing assertions, zero failures and one Windows symlink-permission skip. Six additional regression files completed with 86 passing assertions and zero failures, including the corrected SQLite and voice-streaming cases. TypeScript, root/source ESLint, and source formatting checks passed. The imported assets and configured Connector also passed the live smoke check.

The application remains a fork with retained upstream implementation libraries and license notices; removed product routes and background services cannot be reached through its local interface.
