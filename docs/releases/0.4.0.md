# Hina Desktop 0.4.0

- Click the overlay during an agent recording to discard the recording and type a message. Text replies appear without speech playback.
- Configure the Hina Connector from settings or portable JSON, with connection checks and configurable request timeouts.
- Use Windows push-to-talk for dictation and agent commands, with separate shortcut handling and reliable recording cancellation.
- Choose a Windows speech voice for spoken agent replies and see elapsed time while waiting for a response.
- Apply the Hina visual identity and update mobile Expo dependencies to repair Mobile CI.

The Windows installer preserves the existing Hina Desktop profile and model cache. Install the `.exe` manually or use the application's update check.

The separately deployed Connector also supports a fresh independent session for every desktop request. This server-side change requires updating and restarting Connector; the Windows installer does not install Connector.

This is an unsigned Windows x64 release.
